Privacy Policy

Information about privacy and the current website experience.

Last updated: October 18, 2026

Important: This policy is a starting template for the current website prototype, not a substitute for legal advice. Review and adapt it to the actual services, technologies, jurisdiction, and data practices before publication.

1. About this website

This website uses the name Itrace Bank Financial and currently provides a front-end website presentation. It is not connected to a live banking system, and its sample customer records, balances, and transactions are fictional.

2. Information you enter

The current login, registration, and contact pages are front-end previews. They do not provide a working banking account, create a real customer account, or send contact messages to a support team.

Please do not enter real passwords, banking credentials, account numbers, payment card details, identity documents, or other sensitive personal information into these preview pages.

3. Information collected by hosting services

The website is intended to be hosted using GitHub Pages. GitHub and other infrastructure providers may process technical information, such as server logs, in accordance with their own policies and the services used. Review the applicable provider policies before publishing.

4. Cookies and tracking

This version does not intentionally implement a custom analytics or advertising tracking system. Hosting providers, embedded content, or future integrations may behave differently. Update this section if tracking technologies are added.

5. Data security

A static website does not provide secure banking authentication or protected storage for customer financial records. Do not use this prototype to handle real customer banking information. Any future live service must use suitable security controls and an appropriately protected backend.

6. Third-party services and images

Some pages may load images from an external image provider. When external content is loaded, the provider may receive technical request information under its own policies. Review third-party terms before using external assets in a production website.

7. Children's privacy

This website is not designed to collect personal information from children. No real personal information should be submitted through the current preview forms.

8. Your privacy rights

Privacy rights and legal obligations depend on the location of the people using the website and the organization operating it. Before launching a real service, provide an accurate contact method for privacy enquiries and explain how requests will be handled.

9. Changes to this policy

This policy may need to change when the website's features, hosting, data handling, or integrations change. The published version should reflect the actual practices in use.

10. Contact

For general website questions, visit the Contact Us page. The contact details shown there must be verified and updated before launch.
